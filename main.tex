\begin{abstract}
Precubical sets are a standard tool in the study of concurrent programs.
A 2021 paper by Paliga and Ziemiański showed that the fundamental groupoid path space for 
the final precubical set was exactly the category Braid. 
However, they also showed induced braid subgroups for euclidean sets trivialized. 
In the world of hyperplane arrangements, this kind of trivialization can be resolved
by working in the ``complexified'' space. 
We use this same approach, to build a new, complexified version of the path space, $\Chs$. 
This is homotopy equivalent to the Salvetti Complex of the braid arrangement in for the cube,
but defined over any precubical set. By Salvetti's theorem, then, $\pi_1|\Chs(\square^n)|$ is
is the pure braid group. This gives us a new braid invariant for concurrent programs.
\end{abstract}

\section{Introduction}
This work is in 3 parts. First we'll recap the relevant material in brief.
Second, we will perform the construction of the ``complexified'' path space.
Third, we will study some of its properties.


To begin let's fix some notation, let $\Cube$ be the category of cubes, with face embeddings as morphisms.
Let $\square$ be the precubical sets, defined as the presheaf topos over $\Cube$.
A $\square$ set then has, for each $n \in \N$, a set of $n$-cells denoted $K[n]$.
And, for each $n \in \N$, a face map $d_i^\epsilon$, where $i$ indicates the direction,
and $\epsilon$ is a boolean, with coherence laws. Let $\square^n$ be the standard n-cube.

Furthermore, we often want to consider precubical sets with designated start and end points.
That is bipointed precubical sets, notated $\BPSet$. That is, sets with a start and end.

\section{Wedge Machinery}
We will end up several times in a situtation where we know what to do on cubes, but want to work with serial wedges.
In an effort to keep our proofs better factored, we build some machinery here will enables
a more elegant lifting stategy.

\begin{lemma}
  Let $P$ be a functor $\Cube \Rightarrow Cat$. Then there is an extension

   \[ 
   E(P) : (\BPSet, \lor, 0) \Rightarrow (Cat, \oplus, \emptyset)
   \]
   which is a lax monoid functor extending P via coyoneda.
   Moreover, if $P \square^0$ is empty, then for any serial wedge $\bigvee a$ we get an isomorphism 
   \[
     E(P)(\bigvee a) \simeq \Sigma_i P(\square^{a_i})
   \]
\end{lemma}
\begin{proof}
  The extension is, essentially, the Coend on $\square$. The isomorphism goes by induction.
  At each point, since $P(\square^0)$ is empty, apply $E(P)$ to the pushout diagram trivializes
  the shared point, so we end up with exactly the diagram of a coproduct. 
\end{proof}

\begin{lemma}
  Let $P$ be a functor $\Cube^{op} \Rightarrow Cat$, such that $P \square^0$ is a singleton. Then there is a
   \[ 
   E(P) : (\BPSet, \lor, 0) \Rightarrow (Cat, \times, 1)
   \]
   is a lax monoidal functor extending P via yoneda. 
   Moreover, if $P(\square^0)$ is a singleton, then for any serial wedge $\bigvee a$, we get an isomorphism
   \[ 
     E(P)(\bigvee a) \simeq \Pi_i P(\square^{a_i})
   \]
\end{lemma}
\begin{proof}
  The dual construction. Observe this time that if $P(\square^0)$ is unique, the coherence requirements
  for a wedge are trivial. 
\end{proof}
Together, these give us tools for lifting and decomposing cube maps to tensor maps.

So let us define the cases we care about 
\begin{definition}
  Let $\Coord : \Cube \Rightarrow Cat$ send $\square^n \mapsto [n]$, and a map 
  $f :\square^n \rightarrow \square^m$ is a face inclusion which induces a $[n] \rightarrow [m]$.
  This is a functor. And $[0]$ is empty, so it satisfies the lifting condition.
  This gives us $coordMap: (\bigvee a \longrightarrow \bigvee b) \rightarrow (\Sigma_i [a_i] \rightarrow \Sigma_j [b_j])$
  directly as a monoidal functor.
  This tells us how coordinate positions in $\bigvee a$ translate to positions in $\bigvee b$.
\end{definition}

\begin{lemma}
  The function $coordMap$ is a bijection.
\end{lemma}
\begin{proof}
  We can by induction and monoidality, we can reduce this to just the case $\bigvee a \longrightarrow \square^m$.
  Let's start with injectivity.  We can induct on the size of $a$. The base case is trivial. 
  So we can consider $(\bigvee b) \lor a \longrightarrow \square^m$. 
  Then every vertex the image of $a$ is reachable from the final vertex of the image of $\bigvee b$. 
  Which means the their coordinates greater elementwise.
  Since the image of the induced $[a] \rightarrow [m]$ is only the coordinates that flipped, the images are is disjoint.
  And since $[a] \rightarrow [m]$ is injective, we are done.

  For surjectivity, observe that the serial wedges and cubes admit altitude, and so the altitudes of their final points 
  must agree, so coordMap is indeed a bijection.
\end{proof}

\begin{lemma}
  For any $f:\bigvee a \longrightarrow \bigvee b$, the function $coordMap(f)$ is bijective.
\end{lemma}
\begin{proof}
  The proof needs first breaks up easily via $\lor$, so it suffices to show it for 
  a map $\bigvee a \longrightarrow \square^b$. Then we prove this is an injection by 
  an induction over the wedge, observing that in the cube, if a 0-cell $x$ can reach a 0-cell $y$, 
  it always has more $1$s in its coordinates.
\end{proof}

Critically, this means that every coordinate in $\square^n$ only flips from $0$ to $1$ once 
for each $\bigvee a \longrightarrow \square^n$ as witnessed by $coordMap^{-1}$.
This is the key property that will make our braids well-defined.

\section{The Complexification Construction}
The construction starts by observing that one dimensional serial wedges behave like topes,
or chambers, from the hyperplane configuration world. 
That is, they are the maximally refined elements. Let's start by reviewing the story on the 
braid arrangement side. 

Following Paris, but specifically for the braid arrangement. 
The $n-1$ braid arrangement is a family of hyperplanes in $\R^{n}$ of $\{x_i = x_j\}$ for $0 <= i < j <= n$.
The idea is to give each plane an orientation, so that we can break up $\R^n$ into faces represented as 
functions $\mathbf{Face}:=[n] \rightarrow \{-1,0,1\}$, the covectors. We can order covectors
\[
  x \leq y := \forall i, x(i) = 0 \lor x(i) = y(i)
\]
which gives an order on $\mathbf{Face}$. 
Maximal elements of this order are covectors that are never 0, which are precisely the complement of the hyperplanes.
We call these maximal elements \textbf{topes}.

The main issue with $\mathbf{Face}$ is that it is both interesting and contractible.
The goal of Salvetti's theorem is to build a structure on top of the same covectors that captures
essentially the same information, but with a richer structure. Repeat the process, but with $\C$ instead of $\R$.
We end up with the Salvetti Poset $\Sal$. 
\[
  \Sal = \{(F,C) \in \mathbf{Face} \times \mathbf{Face} \;|\; C \text{ is a tope}\land F \leq C\}
\]
We need one more definition: the composition of two faces 
\[
F \circ G := i \mapsto \text{ if F(i) = 0} \text{ then }Y(i) \text{ else } X(i)
\]
For a tope $C$ and face $F$, we define $C_F$ as the 
\[
  (F,C) \preceq (F',C') := F \leq F' \land C' = F' \circ C
\]
This poset induces a complex, and Salvetti's theorem tells us that it is isomorphic to the configuration space of $n$ points.
So, its fundamental group is pure braids. Intuitively, each face get annotated with a direction, indicated by the tope.
So when we paths cross through faces, they can cause orientation changes. 
These changes are what the braid words represent. 
And in fact, this direction information is what the Configuration Spaces paper retains as well, essentially breaking every tie 
at a face in every possible way.

This construction abstracts a bit, in a way that will make it convienent to construct for us. 
In particular, there's a functor $Tope: Face \Rightarrow \{X \in Face, X \text{ is a tope}\}$
where each face maps to its neighboring topes. And functions between faces induce orientation-preserving maps of topes.
Then the salvetti poset is $\int Tope$. 

To rebuild this generically on the precubical side, let's start with the first positive indicator. 

\begin{definition}
  $\Ch(\square^n) \simeq \mathbf{Face} $
\end{definition}

\begin{definition}
  A serial wedge is \textbf{one dimensional} if all its entries are 1
\end{definition}

\begin{definition}
  Let $\Run(K)$ be the full subcategory of $\Ch(K)$ such that 
  the domains are one dimensional serial wedges.
\end{definition}

\begin{lemma}
  Being one dimensional is preserved under $\lor$, so $\Run(K)$ is a monoidal functor. 
  And in paritcular $List \N \Rightarrow \Run(\bigvee \cdot)$ is a lax monoidal functor.
\end{lemma}

Now, the morphisms we want to build are a bit unusual, because they are built from
degenerecies, which are not morphisms in Precubical. That is, we want to build a map
from an op arrow in $\Ch(K)$ to runs that respect its's coordinate wise projections.
\[
  (\bigvee a \longrightarrow \bigvee b) \rightarrow (\Run(\bigvee b) 
  \rightarrow \Run(\bigvee a) )
\]
Doing this directly is rather painful, so we build a bit a machinery to lift
a cube-level operations to wedge level operations.

So specifically, let $\Edge(K)$ be the chains in $\Refine(K)$ with each cell 1 dimensional.
Then $\Run(K) = \Edge(K)$. 


Now, given a face embedding $(f : \square^n \longrightarrow \square^m)$, it defines a unique
projection of cells of $m$ to cells of $n$, non-increasing on dimension. Call it $\hat{f}$.
So we define
\[
 \rho: (f : \square^n \longrightarrow \square^m) \rightarrow (\Run[\square^m] \rightarrow (\Run[\square^n]))
\]
via 
\[
 \rho': (f : \square^n \longrightarrow \square^m) \rightarrow (\Refine_1[\square^m] \rightarrow (\Refine_1[\square^n]))
\]
by 
\[
  [c_1,...,c_k] \mapsto [\hat{f}(c_1), ...,\hat{f}(c_k)]
\]
Note that this is indeed a one dimensional chain in $\square^n$ because $\hat{f}$ 
never increases dimension, and every projection respects initial/final points.

Now, $\rho$ is a nice. In particular, 
\begin{lemma}
  $\rho : \Cube^{op} \Rightarrow Set$ is a functor, and $\rho (\square^0)$ is a singleton
\end{lemma}
\begin{proof}
  The proof of functorality mostly just exploits the fact that cubes are NSL and admit altitudes.
  So $\Refine_1(\square^n) \simeq \Run(\square^n)$ as sets.
  First, $\rho$ preserves identities, as the projection for with the identity embedding is also the identity.
  Second, if $f : \square^n \rightarrow \square^m$ and $g : \square^m \rightarrow \square^n$ 
  are face embeddings, then their corresponding projections respect composition.

  For the singleton, observe that there $\rho(\square^0) = \Run[\square^0]$, 
  but the only one dimensional serial wedge which maps into $\square^0$ is the the empty one. 
  So indeed $\rho(\square^0)$ is a singleton.
\end{proof}

Now, we can use our lifting machinery to lift $\rho$ to $\hat{\rho} : \BPSet \Rightarrow Cat$.
There is also a forgetful functor $W(K): \Ch(K) \Rightarrow BPSet$ sending $\bigvee a \rightarrow K \mapsto \bigvee a$.
Then we can define our key functor
\[
\Lines(K) := E(\rho) \circ W(K)
\]
\[
\Chs(K) := \int Lines
\]

Defining $\Chs$ abstractly has some convienences later. 
In particular, since E is functorial, we can replace $\rho$ with an equivalent presheaf
to produce an equivalence of $\Chs(\square^n)\simeq \Sal(n)$. 
But it's worth unpacking the definition of $\Chs$ to have a more concrete presentation of it.

Objects of $\Chs(K)$ are pairs 
\[ 
  (\bigvee a \longrightarrow K, x : \Run[\bigvee a]), \text{ I.E. } (\bigvee a \longrightarrow K, \bigvee[1,...,1] \longrightarrow \bigvee a) 
\]
The intuition here matches the Salvetti story precisely, we have a wedge map into $K$, coupled with orientation info about it.
Morphisms are a little uglier. A morphism
\[ 
  (\bigvee a \longrightarrow K, x : \Run[\bigvee a]) \longrightarrow (\bigvee b \longrightarrow K, y : \Run[\bigvee b])
\]
unpacks to 
\begin{enumerate}
  \item A morphism $f : (\bigvee a \longrightarrow K) \longrightarrow (\bigvee b \longrightarrow K )$ I.E. a commuting $f':\bigvee a \longrightarrow \bigvee b$.
  \item A $\phi : \Lines(F)(x) \rightarrow y$, in other words $\phi: E(\rho)(f')(x) \rightarrow y$.
  This means we are taking a run $x$, passing it through the projection maps, and comparing it with $y$. 
  The key observation here is that these morphisms can be represented by permutations. A map in $\Run[\bigvee b]$ is a map 
  $\bigvee[1,..,1] \rightarrow \bigvee[1,..,1]$. Which by the coordinate map, a bijection $[n] \rightarrow [n]$. 
  Let $\tau(f)$ be that permutation.
\end{enumerate}

\section{Braidings}
Let $f$ be a morphism in $\Chs(K)$. 
Let $\tau(f)$ be the corresponding permutation.
The main trick is to show that $\tau$ respects composition up to braiding. That is,
\[
  R: \Chs(K) \Rightarrow Braid
\]
sending objects to the objet with the appropriate length, and $f \mapsto \tau(f)$ is a functor.
For our purposes, it will be easier to use an unusual presentation of the braids, the Garside 
Germ presentation, generated by permutations, up to a relation about the height of the permutation.
This is a convienent target, because the permutation height rule aligns nicely with the fact 
that you can only refine each coordinate once.

It also happens to agree with the construction from Salvetti's theorem, so this does indeed 
duplicate the Salvetti work, but for precubical sets.

\section{Relationship to the Salvetti Complex}
The key fact here is that our story mirrors the salvetti story, on the nose, for cubes.
That is, the face complex is exactly $\Ch(\square^n)$, and the salvetti complex is exactly $\Chs(\square^n)$.
I'd argue this explains why the braid invariant from `Configuration Spaces' collapsed, 
and why this complexification survives. However, it does suggest that 
\begin{enumerate}
  \item The salvetti complex is also $\Ch(Z)$, so the quotiont by the free action some is also 
        related to the complexification story
  \item $\Chs(Z)$ is bigger than Braid, so something interesting is happening

\end{enumerate}
